# Non-Markdown documents (chapter 4)

A text PDF, a Word document, and a scanned PDF with no text layer, for the document loaders in chapter 4.
Each file has a `.meta.json` sidecar with its title, policy number, department, and access list, standing in
for the source system's metadata. A file without a sidecar is visible to nobody. All content is fictional.
`scripts/generate-ch04-samples.py` regenerates them.
