## What PriorAuthBot can do now

PriorAuthBot answers Deductible Dynamics staff questions from the documents in `samples/documents`, and only from the documents the signed-in user may open. A nurse and a contractor who ask "Can I work remotely?" get different, correct answers. A contractor who asks about the sepsis protocol gets "I don't know based on the documents you can access."

| Piece | Where |
|---|---|
| Ingestion worker: load, chunk, embed, upsert, delete | `src/PriorAuthBot.Api/Ingestion/IngestionWorker.cs`, `src/PriorAuthBot.Core/Ingestion/IngestionPipeline.cs` |
| Structural and fixed-size chunkers | `src/PriorAuthBot.Core/Ingestion/` |

## Endpoints

| Endpoint | Chapter | What it does |
|---|---|---|
| `POST /chat` | 2 | Streams a reply straight from the model, no documents |
| `POST /search` | 6 | Permission-aware search; returns the chunks the caller may see |
| `POST /ask` | 7 | Grounded answer with sources, or a decline |

All three require sign-in. Production uses Entra ID bearer tokens (`Auth:JwtBearer`). In the Development environment, `Auth:Mode` is `Demo` and the `X-Demo-User` header picks a persona from `appsettings.Development.json`.

## Configuration

| Setting | Default | Notes |
|---|---|---|
| `AI:Provider` | `Ollama` | `Ollama`, `OpenAI`, or `Offline` (no model; for tests) |
| `VectorStore:Provider` | `InMemory` | `Postgres` uses `ConnectionStrings:priorauthbot` (pgvector) |
| `Retrieval:MinScore` | `0.6` | Measured per embedding model with the golden set |
| `Chunking:MaxTokens` / `OverlapTokens` | 350 / 50 | See the chunking experiment in the CI job summary |
| `Ingestion:Interval` | 5 minutes | Worst-case delay for a permission change or delete to reach the index |
| `Identity:Groups` | | Entra group object ID to ACL group name |

To use pgvector, run `docker compose up -d` and set `VectorStore:Provider` to `Postgres`. To use OpenAI, set `AI:Provider` to `OpenAI` and store the key with `dotnet user-secrets set "AI:OpenAI:ApiKey" <key>`.

## Package change in this chapter

`Microsoft.SemanticKernel.Connectors.*` are deprecated and fail at run time with `Microsoft.Extensions.VectorData.Abstractions` 11. This tag uses their stable replacements, `CommunityToolkit.VectorData.InMemory` and `CommunityToolkit.VectorData.PgVector`.
