# Chapter 3: Prompts as code and structured output

Tag: `ch03` · Compare: `git diff ch02 ch03`

## What PriorAuthBot can do now

Every question can be classified into a typed `QuestionIntent` (department, sensitivity, mentions-PHI flag), validated, and routed. Prompts live in a versioned folder, are reviewed like code, and are pinned by snapshot tests.

| Piece | Where |
|---|---|
| Versioned prompts and few-shot examples | `src/PriorAuthBot.Core/Prompts/Templates/` |
| Prompt loading and `{{placeholder}}` rendering | `src/PriorAuthBot.Core/Prompts/PromptLibrary.cs` |
| `QuestionIntent` with DataAnnotations | `src/PriorAuthBot.Core/Classification/QuestionIntent.cs` |
| Structured output: strict parsing, validation, retry | `src/PriorAuthBot.Core/AI/StructuredOutput.cs` |
| Classifier and router | `src/PriorAuthBot.Core/Classification/` |
| Snapshot tests | `tests/PriorAuthBot.Tests/PromptSnapshotTests.cs`, `tests/PriorAuthBot.Tests/Snapshots/` |
| 16 labeled questions, run against Ollama in CI | `tests/PriorAuthBot.Tests/GoldenSet/classification-set.json`, `tests/PriorAuthBot.Tests/LiveClassifierTests.cs` |
| Who reviews prompt changes | `.github/CODEOWNERS` |

## Try it

```bash
curl -X POST http://localhost:5080/classify -H "X-Demo-User: nurse" -H "Content-Type: application/json" \
  -d '{"question":"Member DD-4471902 had an MRI denied. What criteria did we use?"}'
```

`/classify` returns `502 Bad Gateway` when the model's reply still fails validation after one retry. With `AI:Provider` set to `Offline` there is no model to classify with, so it always does.

## Changing a prompt

1. Copy the file to a new version (`classify-question.v2.md`) and point the constant in `PromptLibrary` at it.
2. Run the tests. The snapshot test fails and writes `Snapshots/classify-question.v1.received.txt` (or a new snapshot for v2).
3. Read the diff. If it is what you meant, approve it: `PRIORAUTHBOT_UPDATE_SNAPSHOTS=1 dotnet test --solution MasteringAI.slnx`.
4. Commit the prompt and the snapshot together. CODEOWNERS sends the pull request to the prompt owners.
