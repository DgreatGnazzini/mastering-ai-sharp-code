## What PriorAuthBot can do now

PriorAuthBot API v0: `POST /chat` streams a reply from the configured provider as server-sent events. Azure OpenAI (signed in with Entra ID, no keys), OpenAI, and Ollama all sit behind `IChatClient`, chosen in configuration. Every chat client runs through the same middleware pipeline, provider failures become HTTP statuses a client can act on, and each user has a rate limit.

| Piece | Where |
|---|---|
| Providers, keyed clients, and the middleware pipeline | `src/PriorAuthBot.Core/AI/AiServiceCollectionExtensions.cs` |
| Provider settings | `src/PriorAuthBot.Core/AI/AiOptions.cs`, `src/PriorAuthBot.Api/appsettings.json` |
| Retry middleware (429, 5xx, timeouts, Retry-After) | `src/PriorAuthBot.Core/AI/RetryingChatClient.cs` |
| Classifying provider failures | `src/PriorAuthBot.Core/AI/ChatFailure.cs` |
| Streaming endpoint | `src/PriorAuthBot.Api/ChatEndpoint.cs` |
| Per-user rate limit | `src/PriorAuthBot.Api/Program.cs` |
| Sign-in: Entra ID bearer tokens, or demo personas in Development (chapter 7 explains them) | `src/PriorAuthBot.Api/Program.cs`, `src/PriorAuthBot.Api/Auth/DemoAuthenticationHandler.cs`, `src/PriorAuthBot.Api/appsettings.Development.json` |
| A model-free provider for tests and CI | `src/PriorAuthBot.Core/AI/OfflineChatClient.cs` |
| Tests | `tests/PriorAuthBot.Tests/ChatApiTests.cs`, `RetryingChatClientTests.cs`, `AiServiceCollectionTests.cs`, `LiveChatTests.cs` |

## Try it

```bash
curl -N -X POST http://localhost:5080/chat -H "X-Demo-User: nurse" -H "Content-Type: application/json" \
  -d '{"message":"In two sentences, what is prior authorization?"}'
```

The reply arrives as `delta` events, then `done`. A failure before the first token is an HTTP status: 503 if the provider is busy or down, 504 on a timeout, 422 if its content filter blocked the prompt. A failure after the first token arrives as an `error` event, because the status has already been sent.

## Switching providers

| Provider | Settings | Credentials |
|---|---|---|
| `Ollama` (default) | `AI:Ollama:Endpoint`, `ChatModel` | None |
| `AzureOpenAI` | `AI:AzureOpenAI:Endpoint` (the resource's `/openai/v1/` URL), `ChatDeployment` | Entra ID through `DefaultAzureCredential`: `az login` locally, managed identity in Azure. Your account needs the **Cognitive Services OpenAI User** role on the resource. |
| `OpenAI` | `AI:OpenAI:ChatModel` | `dotnet user-secrets set "AI:OpenAI:ApiKey" <key>` |
| `Offline` | None | None. No model: replies say so. For tests and CI. |

Set `AI:Ollama:ClassifierModel` (or `ClassifierDeployment`, `ClassifierModel`) to run chapter 3's classifier on a smaller model.
