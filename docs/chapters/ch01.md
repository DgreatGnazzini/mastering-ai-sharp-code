## Run the local environment

You need Docker Desktop or Podman. The first run downloads the Ollama models (about 2.3 GB).

```bash
dotnet run --project src/PriorAuthBot.AppHost
```

The console prints a link to the Aspire dashboard, which shows PostgreSQL, Ollama, the model downloads, and the API with its logs. No Aspire? `compose.yaml` starts the same containers.

## Count tokens and estimate cost

```bash
dotnet run --project tools/PriorAuthBot.TokenCost -- samples/documents/pto-policy.md
dotnet run --project tools/PriorAuthBot.TokenCost -- --text "Member DD-4471902, DOB 03/14/1961" --show-tokens
dotnet run --project tools/PriorAuthBot.TokenCost -- --text "Can I carry PTO over?" --output-tokens 150 --requests-per-day 4000
```

Prices come from `tools/PriorAuthBot.TokenCost/prices.json`. They are example list prices; replace them with your own price sheet.
