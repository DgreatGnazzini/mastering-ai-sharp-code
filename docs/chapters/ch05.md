# Chapter 5: Embeddings and semantic search

Tag: `ch05` · Compare: `git diff ch04 ch05`

## What PriorAuthBot can do now

`POST /catalog/search` finds Deductible Dynamics policies by meaning: "I left my laptop on the train" finds the lost-device policy, which never uses those words. About 200 policy summaries are embedded once, in batches, held in memory, and searched with exact nearest-neighbor search in plain C# using `TensorPrimitives`. Every embedding generator now runs through a middleware pipeline like the chat clients: the PHI guard for unapproved providers, logging, and an optional cache.

| Piece | Where |
|---|---|
| Nearest-neighbor search in plain C# | `src/PriorAuthBot.Core/Search/SemanticIndex.cs` |
| The catalog: load, embed in batches, search | `src/PriorAuthBot.Core/Search/PolicyCatalog.cs` |
| Embedding pipeline and cache | `src/PriorAuthBot.Core/AI/AiServiceCollectionExtensions.cs` (`UsePriorAuthBotEmbeddingPipeline`) |
| PHI guard for embeddings | `src/PriorAuthBot.Core/AI/PhiGuardEmbeddingGenerator.cs` |
| Catalog data | `samples/catalog/policy-catalog.json`, generated by `scripts/generate-ch05-catalog.py` |
| Labeled queries | `tests/PriorAuthBot.Tests/Catalog/catalog-queries.json` |
| Tests | `SemanticSearchTests.cs`, `CatalogApiTests.cs`, `LiveSemanticSearchTests.cs` |

## Try it

```bash
curl -X POST http://localhost:5080/catalog/search -H "X-Demo-User: nurse" -H "Content-Type: application/json" \
  -d '{"query":"I left my laptop on the train"}'
curl -X POST http://localhost:5080/catalog/search -H "X-Demo-User: nurse" -H "Content-Type: application/json" \
  -d '{"query":"CPT 72148"}'
```

The first finds the right policy. Compare the second: exact codes are where semantic search struggles, and chapter 8 adds keyword search to fix it.

## Configuration

| Setting | Default | Meaning |
|---|---|---|
| `Catalog:BatchSize` | `32` | Texts per embedding request |
| `Catalog:QueryPrefix`, `Catalog:DocumentPrefix` | empty | Task prefixes for models trained with them, such as `search_query: ` and `search_document: ` for nomic-embed-text |
| `AI:CacheEmbeddings` | `false` | Cache embeddings in memory, keyed by text and request options (not the model: clear it when you change models) |
