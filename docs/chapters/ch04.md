# Chapter 4: Documents, images, and forms

Tag: `ch04` · Compare: `git diff ch03 ch04`

## What PriorAuthBot can do now

PriorAuthBot reads more than Markdown. A document loader turns text PDFs, scanned PDFs, Word files, and images into one normalized `SourceDocument` with page numbers and access metadata, and ingestion uses it. Scanned pages go to OCR: a vision model through `IChatClient`, or Azure AI Document Intelligence. `POST /intake` takes a scanned prior authorization form from a claims analyst and returns typed, validated fields and a route: straight to clinical review, or to a person for data entry when anything does not check out. Hosted providers that are not approved for PHI get a guard that redacts text and refuses images.

| Piece | Where |
|---|---|
| Loader for every format | `src/PriorAuthBot.Core/Documents/DocumentLoader.cs` |
| PDF (text and scanned), Word | `PdfDocumentLoader.cs`, `WordDocumentLoader.cs` |
| Access metadata for non-Markdown files | `DocumentMetadata.cs` (a `.meta.json` sidecar; none means deny-all) |
| OCR | `IOcrService.cs`, `VisionOcrService.cs`, `DocumentIntelligenceOcrService.cs` |
| Intake form type, extraction, routing | `src/PriorAuthBot.Core/Intake/` |
| Extraction prompt | `src/PriorAuthBot.Core/Prompts/Templates/extract-intake-form.v1.md` |
| Redaction and the PHI guard | `src/PriorAuthBot.Core/Privacy/PhiRedactor.cs`, `src/PriorAuthBot.Core/AI/PhiGuardChatClient.cs` |
| Endpoint | `src/PriorAuthBot.Api/IntakeEndpoint.cs` |
| Samples | `samples/files/`, `samples/intake/`, regenerated by `scripts/generate-ch04-samples.py` |
| Tests | `FileLoaderTests.cs`, `IntakeTests.cs`, `IntakeApiTests.cs`, `PhiGuardTests.cs`, `LiveIntakeTests.cs` |

## Try it

Pull the vision model once (the AppHost does it for you):

```bash
docker compose exec ollama ollama pull qwen2.5vl:3b
```

Submit the sample form as the claims analyst persona. Any other persona gets 403.

```bash
curl -X POST http://localhost:5080/intake -H "X-Demo-User: claims" \
  -F "file=@samples/intake/intake-form-001.png;type=image/png"
```

To ingest the PDF, Word, and scanned samples instead of the Markdown policies, set `Ingestion:DocumentsPath` to `../../samples/files`.

## Configuration

| Setting | Default | Meaning |
|---|---|---|
| `AI:Ollama:VisionModel` | `qwen2.5vl:3b` | Model for OCR and form extraction. `AzureOpenAI:VisionDeployment` and `OpenAI:VisionModel` fall back to the chat model. |
| `Documents:Ocr` | `Vision` | `Vision`, `DocumentIntelligence`, or `None` (scanned pages are skipped and logged). |
| `Documents:DocumentIntelligenceEndpoint` | none | The Document Intelligence resource. Sign-in is Entra ID, like Azure OpenAI; your account needs **Cognitive Services User**. |
| `AI:ApprovedForPhi` | true for Ollama and Offline, false otherwise | Set to `true` for Azure OpenAI only when a business associate agreement covers the subscription. |
| `Intake:AllowedGroup` | `Claims` | The group allowed to call `/intake`. |
